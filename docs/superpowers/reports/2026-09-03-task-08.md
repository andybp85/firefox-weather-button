## Deviations from the plan

1. **`no direction` instead of `direction not reported`.** The plan's `describeSource` returns
   `'direction not reported'` for a measured wind whose station sent no `wdir`. The spec (Wind plaque, and Resolved
   decision 2) gives that case, and calm, the one wording `no direction`. The spec wins, so `describeSource` returns
   `'no direction'` for an absent direction and the calm branch now routes through `describeWindDirection` rather
   than repeating the literal. Covered by a new test, *render claims no heading for a measured wind whose station
   sent none*.
2. **The plan's footer test asserted `ended 66m ago`; the correct value is `ended 1h ago`.** `describeElapsed` is
   unchanged shipped behaviour: under 60 minutes it prints minutes, otherwise hours. The fixture pins `now` 66
   minutes after the tendency's window close, so the value rounds to hours. The expectation was corrected (with a
   comment) rather than the code — the two footer ages stay distinguishable (`6m ago` vs `1h ago`), and the test now
   exercises both of `describeElapsed`'s units.
3. **`renderWind`'s calm branch.** Written as one `writeReading` call with the unit chosen by a ternary, rather than
   the plan's two early-return branches, so the calm and measured paths share the direction line.

Everything else is the plan's text as written, including the comment blocks.
